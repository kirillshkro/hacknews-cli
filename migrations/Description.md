# migrations

SQL миграции для PostgreSQL.

## Назначение

Эта директория содержит:
- Migrations для создания и изменения схемы базы данных
- Создание таблицы items
- Создание индексов
- Управление версиями схемы

## Структура

- `001_create_items_table.up.sql` - создание таблицы
- `001_create_items_table.down.sql` - откат миграции
- `002_create_indexes.up.sql` - создание индексов
- `002_create_indexes.down.sql` - откат миграции

## Особенности

- Именование: `NNN_описание.up.sql` и `NNN_описание.down.sql`
- Каждая миграция имеет обратную
