# internal/config

Парсинг и валидация конфигурации из переменных окружения.

## Назначение

Эта директория содержит:
- `app_config.go` - структура AppConfig с параметрами всех компонентов сервиса
- Загрузка конфигурации из переменных окружения через библиотеку cleanenv
- Валидация значений и применение значений по умолчанию

## Структура

- `app_config.go` - основная структура конфигурации

## Параметры конфигурации

- **API** - параметры HTTP-сервера (порт, таймауты, режим)
- **Database** - параметры PostgreSQL (хост, порт, пул соединений)
- **Redis** - параметры Redis (хост, порт, пул соединений)
- **Scraper** - параметры синхронизации (интервал, размер пула воркеров)
- **Cache** - параметры кэширования (TTL для списков и деревьев комментариев)
