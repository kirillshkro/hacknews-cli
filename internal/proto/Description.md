# internal/proto

Контракты Protobuf для микросервисов.

## Назначение

Эта директория содержит:
- Файлы .proto с определением сообщений и сервисов
- Контракты для gRPC/Protobuf
- Генерация Go-кода из protobuf определений

## Структура

- `app.proto` - основной контракт сервиса

## Особенности

- Определение всех сообщений для API
- Определение сервиса HackerNewsService
- Генерация кода через protoc
