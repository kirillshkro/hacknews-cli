# internal/repository

Слой данных - запросы к PostgreSQL.

## Назначение

Эта директория содержит:
- Интерфейсы для работы с базой данных (ItemRepository)
- Реализация CRUD операций для сущности Item
- Запросы для получения списков статей
- Запросы для получения деревьев комментариев
- Транзакции для сложных операций

## Структура

- `item_repository.go` - интерфейс и реализация
- `queries.go` - SQL запросы

## Особенности

- Использование sqlx для типобезопасных запросов
- Поддержка транзакций
- Параметры для пагинации
