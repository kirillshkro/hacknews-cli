# internal/redis

Подключение и управление пулом соединений с Redis.

## Назначение

Эта директория содержит:
- Инициализацию подключения к Redis через go-redis
- Настройку пула соединений (размер, таймауты)
- Проверку работоспособности соединения
- Закрытие соединения при завершении работы

## Структура

- `redis.go` - функции для подключения и управления соединениями

## Особенности

- Использует библиотеку go-redis
- Настраивает пул соединений согласно конфигурации
- Проверяет соединение через команду PING
