# internal/handler

Gin контроллеры (HTTP обработчики).

## Назначение

Эта директория содержит:
- Обработчики HTTP запросов для Gin
- Разбор и валидация входящих запросов
- Вызов бизнес-логики (service)
- Формирование HTTP ответов
- Обработка ошибок

## Структура

- `item_handler.go` - обработчики для статей
- `health_handler.go` - обработчики проверки здоровья

## Особенности

- Использование middleware для валидации
- Корректные HTTP коды ответов
- Логирование ошибок
