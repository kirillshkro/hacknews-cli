# internal/db

Подключение и управление пулом соединений с PostgreSQL.

## Назначение

Эта директория содержит:
- Инициализацию подключения к PostgreSQL через sqlx
- Настройку пула соединений (размер, таймауты)
- Проверку работоспособности соединения
- Закрытие соединения при завершении работы

## Структура

- `database.go` - функции для подключения и управления соединениями

## Особенности

- Использует библиотеку sqlx для удобных запросов
- Настраивает пул соединений согласно конфигурации
- Проверяет соединение при инициализации
