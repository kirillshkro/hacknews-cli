# internal/service

Бизнес-логика микросервиса.

## Назначение

Эта директория содержит:
- Логика получения списков статей (с проверкой кэша)
- Логика получения деревьев комментариев (с проверкой кэша)
- Координация между репозиторием и кэшем
- Обработка ошибок

## Структура

- `item_service.go` - основная бизнес-логика

## Особенности

- Проверка кэша перед обращением к БД
- Сохранение результатов в кэш
- Обработка ошибок и ретраи
