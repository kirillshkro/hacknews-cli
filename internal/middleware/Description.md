# internal/middleware

Middleware для Gin (gzip, таймауты, логирование).

## Назначение

Эта директория содержит:
- Middleware для сжатия ответов (gzip)
- Middleware для ограничения таймаутов
- Middleware для логирования запросов
- Middleware для обработки ошибок
- Middleware для CORS (если необходимо)

## Структура

- `gzip.go` - сжатие ответов
- `timeout.go` - ограничение таймаутов
- `logging.go` - логирование
- `error.go` - обработка ошибок

## Особенности

- Сжатие только для текстовых ответов
- Таймауты 2-3 секунды для мобильных сетей
- Структурированное логирование
