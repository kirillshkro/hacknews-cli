# internal/scraper

Парсинг и загрузка данных с Firebase Hacker News API.

## Назначение

Эта директория содержит:
- Функции для получения списков статей (топ, новые) с Firebase API
- Скачивание отдельных элементов по ID
- Обработка ошибок и ретраев
- Параллельная загрузка элементов с использованием горутин

## Структура

- `firebase.go` - функции для работы с Firebase API
- `parser.go` - парсинг JSON ответов

## Особенности

- Таймауты запросов (2-3 секунды) для мобильных сетей
- Ретраи при временных сбоях
- Параллельная загрузка элементов через пул горутин
