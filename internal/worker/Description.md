# internal/worker

Пул горутин и логика фоновой синхронизации.

## Назначение

Эта директория содержит:
- Реализацию пула воркеров для параллельной обработки элементов
- Логическую синхронизацию данных с Firebase API
- Управление очередью задач
- Инвалидацию кэша при изменениях

## Структура

- `worker_pool.go` - пул горутин для параллельной обработки
- `sync.go` - основная логика синхронизации

## Особенности

- Настраиваемый размер пула воркеров (по умолчанию 10)
- Очередь задач с блокировкой
- Graceful shutdown при завершении работы
