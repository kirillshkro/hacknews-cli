# cmd/worker

Точка входа фоновой синхронизации с Firebase Hacker News API.

## Назначение

Эта директория содержит main.go для запуска воркера, который:
- Периодически синхронизирует списки статей (топ и новые) с Firebase API
- Скачивает и сохраняет новые/обновленные элементы в PostgreSQL
- Использует пул горутин для параллельной обработки
- Инвалидирует кэш в Redis при изменениях

## Структура

- `main.go` - точка входа, инициализация зависимостей и запуск воркера

## Зависимости

- `internal/config` - загрузка конфигурации
- `internal/db` - подключение к PostgreSQL
- `internal/redis` - подключение к Redis (инвалидация кэша)
- `internal/scraper` - логика парсинга Firebase API
- `internal/worker` - пул горутин и логика синхронизации
