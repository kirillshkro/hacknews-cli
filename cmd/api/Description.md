# cmd/api

Точка входа HTTP API (Gin) микросервиса.

## Назначение

Эта директория содержит main.go для запуска HTTP-сервера Gin, который предоставляет REST API для:
- Получения списков статей (топ и новые)
- Получения дерева комментариев
- Проверки здоровья сервиса

## Структура

- `main.go` - точка входа, инициализация зависимостей и запуск сервера

## Зависимости

- `internal/config` - загрузка конфигурации
- `internal/db` - подключение к PostgreSQL
- `internal/redis` - подключение к Redis
- `internal/service` - бизнес-логика
- `internal/handler` - HTTP контроллеры
- `internal/middleware` - middleware (gzip, таймауты, логирование)
