# pkg/utils

Утилитарные функции.

## Назначение

Эта директория содержит:
- Вспомогательные функции общего назначения
- Функции для форматирования и преобразования данных
- Утилиты для работы с временем
- Функции для логирования

## Структура

- `time.go` - утилиты для работы с временем
- `strings.go` - строковые утилиты
- `logger.go` - функции логирования

## Особенности

- Чистые функции без побочных эффектов
- Покрытие тестами
