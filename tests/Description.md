# tests

Тесты микросервиса.

## Назначение

Эта директория содержит:
- Интеграционные тесты
- E2E тесты
- Тесты для проверки взаимодействия между компонентами
- Тесты производительности

## Структура

- `integration_test.go` - интеграционные тесты
- `e2e_test.go` - сквозные тесты
- `performance_test.go` - тесты производительности

## Особенности

- Использование testcontainers для запуска БД и Redis
- Покрытие критических сценариев
- Проверка таймаутов и ограничений
